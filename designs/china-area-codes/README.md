# 中国大陆电话区号与车牌学习表

在仓库根目录启动 HTTP 服务后访问 `/china/`。旧 `/designs/china-area-codes/` 入口保留参数并跳转到新页面。专题资源继续存放于此目录，页面不依赖外部脚本或在线地图服务。

- 地图版：省份使用主要区号前缀着色，06 补充分配城市和三位区号城市单独用点标示。
- 点击省份后用连续的 SVG 相机缩放动画进入省内地图，标注地级市、自治州、地区、省直辖单位及其现用区号。31 个省级行政区共 452 个地图单位，直辖市按区县展示；可选城市高亮、切省、返回全国及展开大图。尊重系统的减少动态效果设置。
- 地图为默认视图；右侧适配统一导航，宽度约 370—420px，以圆框展示当前城市的电话区号、车牌。窄屏自动改为上下布局，并在地图上方提供省份切换；密集标注使用独立位置及连接真实城市中心的引线。
- 对照表：按省份、城市、电话区号、车牌四列展开；点击省份可返回相应省内地图。支持前缀过滤、文字搜索、URL 分享和浏览器打印。
- 页面仅保留地图与对照表。旧记忆版、圆圈版 URL 自动回落至地图，保留原省份和筛选条件。
- 城市标签、详情列表、对照表同时显示蓝色车牌前缀。共用电话区号按城市拆分，增补车牌并列显示；搜索支持车牌、省级简称，忽略英文字母大小写及空格。

`plates.js` 是独立的车牌区域对照快照，核对日期为 2026-11-02，包含 31 省级行政区、452 个地图单位的对应信息及来源。`plate-lookup.js` 负责与电话本地网关联；更新城市底图时应同步检查行政代码。直辖市区县只标全市简称（如「京牌」），不把字母错误分配给区县；表格与短区号例子以「京A等」表示。存量及历史代码在备注中说明，不代表仍可新领。多个城市共用的车牌代码不强行按城市拆分。车牌基础对照来自[中国地图网](https://zhongguoditu.com/chepai/)及[号牌区域分配](https://zh.wikipedia.org/wiki/中华人民共和国民用机动车号牌)，杭州浙M、武汉鄂W、临沂鲁W等增补以页面列出的政府或公安公告交叉核对。特殊、行业及其他非普通区域号牌不做穷举。

采用含国内长途字冠 0 的常见写法。按主要本地网整理；不枚举所有边界村镇、跨区接入、县级例外及兵团城市。共用区号合并展示，同一代码在一个省份出现多行时统计去重。没有定时自动刷新，整理日期为 2026-10-31。

`china.geojson` 是 2026-10-31 从阿里云 DataV `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json` 获取的原始几何。`map.js` 为同份数据预先投影后的路径，Albers 等积圆锥投影的标准纬线为 25°、47°，中央经线 105°。南海岛屿以附图展示。几何不用于精确测绘。

`cities/<省份两位代码>.json` 为同投影的省内地图，来源为 DataV `<省份六位代码>_full.json`，按需从本网站载入。路径经简化、保留真实边界；构建脚本为 `build-city-maps.py`。`cities/manifest.json` 记录各省单位数。三沙以南海岛屿入口展示；旧边界底图未收录的新星、白杨、草湖三市列在地图内的补充列表，不绘制推测边界。它们的区号分别为 0902、0901、0998，依据公开现用联系方式核对。海西州、伊犁州等多区号辖区分别列出区号和说明。
