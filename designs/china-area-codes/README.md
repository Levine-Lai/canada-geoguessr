# 中国大陆电话区号学习表

打开 `index.html` 或在仓库根目录启动 HTTP 服务后访问 `/designs/china-area-codes/`。页面不依赖外部脚本或在线地图服务。

- 地图版：省份使用主要区号前缀着色，06 补充分配城市和三位区号城市单独用点标示。
- 圆圈版：01—09 各组按省份归纳，02 按主要城市归纳。
- 对照表：按省份、主要本地网展开。支持前缀过滤、文字搜索、URL 分享和浏览器打印。

采用含国内长途字冠 0 的常见写法。按主要本地网整理；不枚举所有边界村镇、跨区接入、县级例外及兵团城市。共用区号合并展示，同一代码在一个省份出现多行时统计去重。没有定时自动刷新，整理日期为 2026-10-31。

`china.geojson` 是 2026-10-31 从阿里云 DataV `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json` 获取的原始几何。`map.js` 为同份数据预先投影后的路径，Albers 等积圆锥投影的标准纬线为 25°、47°，中央经线 105°。南海岛屿以附图展示。几何不用于精确测绘。

来源与旧号合并记录在页面“口径与来源”中，可直接打开核对。
